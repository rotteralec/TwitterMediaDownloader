A self-hostable web app that turns an X/Twitter link into a downloadable or shareable MP4. Also works with GIFs, transcoding silent MP4 into an animated .gif with ffmpeg.
FastAPI backend, vanilla-JS frontend, shipped as a hardened Docker image.
